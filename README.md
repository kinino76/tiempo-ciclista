# El tiempo ciclista

Previsión del tiempo pensada para salir en bici, con el viento como protagonista:
viento medio, rachas y dirección, viento de cara o a favor en cada tramo de tu ruta (GPX),
temperatura, sensación rodando y lluvia, y la mejor hora para salir.

Datos: [Open-Meteo](https://open-meteo.com/). Mapa: © OpenStreetMap, © CARTO.

Web: https://kinino76.github.io/tiempo-ciclista/
